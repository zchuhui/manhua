# drafts 目录说明

```
drafts/
  问道无门/
    正文/
      卷一_001-034.md   ← 卷一正文（第1—34章）
      卷二_035-050.md   ← 卷二正文（第35—50章）
    设定/
      剧情纲要_第7-50章.md
```

- 正文是唯一权威文本；网页阅读器由 `web/build-reader.mjs` 从 `正文/` 生成 `docs/data/`。
- 旧稿、重复稿、截断稿归档在 `../archive/drafts_2026-11-04/`，不参与构建。
- 章节标题格式：`## 第NNNN章 标题`；段落首行全角缩进。
