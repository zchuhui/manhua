# 《万古至尊》分布式通读指南（团队共读项目）

## 项目背景
工作目录 D:\projects\manhua 下有一本网络小说《万古至尊》（作者：太一生水），
已转换为 UTF-8 并拆分为 25 个段落文件，供团队分工精读。目标：完整通读全书 2406 章，
产出结构化读书笔记，供后续小说分析 / 漫画改编使用。

## 小说基本信息
- 书名：《万古至尊》
- 作者：太一生水
- 类型：东方玄幻 / 修真 / 转世重生流
- 规模：2406 章，约 810 万字（8,108,454 字符）
- 主角：李云霄（前世为十大封号武帝之一的「破军武帝」古飞扬，陨落后十五年在天水国公子李云霄身上觉醒记忆）

## 已准备好的文件（工作目录 D:\projects\manhua）
- work/novel_utf8.txt        —— 全书 UTF-8 全文（唯一权威文本）
- work/chapters.json         —— 章节索引数组：[{n:章节号,title:标题,start:起始字符偏移,end:结束字符偏移,chars:字数}]
- work/titles.txt            —— 全部章节标题（每行一个）
- work/segments/seg_XX.txt   —— 分段文本（第01段=第1~100章，...，第24段=第2301~2400章，第25段=第2401~2406章）
- work/segments/index.json   —— 分段索引（from/to/章数/字符数）

段落文件格式：开头是「========== 第XX段：第A章 ~ 第B章 ==========」+ 本段 100 个章节标题列表，
之后是正文，每章以「第XXXX章 标题」单独一行开始，正文以全角空格缩进。

## 你负责的段落
见共享任务描述。每人负责 2~4 个段落，逐段完成。

## 阅读方法（重要）
每个段落约 33 万字符 / 6000~9500 行，一次读不完。请分块阅读：
1. 用 read 工具读段落文件，每块约 1500~1800 行（约 50~60 章）；务必先看段首的章节标题列表把握走向。
2. 每读完一块，立刻把该块的笔记**追加**写入笔记文件（不要攒到最后），这样即使上下文吃紧也不会丢信息。
3. 读完全段后，按模板整理成完整笔记文件。

需要单独精读某一章全文时，可用 run_code 执行如下代码（把章号换成你要的）：
```ts
const fs = await import('node:fs');
const text = fs.readFileSync('D:\\projects\\manhua\\work\\novel_utf8.txt', 'utf8');
const chs = JSON.parse(fs.readFileSync('D:\\projects\\manhua\\work\\chapters.json', 'utf8'));
const pick = chs.filter(c => [123, 456].includes(c.n));  // 改章号
for (const c of pick) console.log('===== ' + c.title + ' =====\n' + text.slice(c.start, c.end));
```
（路径注意：D:\projects\manhua 是工作目录，相对路径 work/... 即可。）

## 记录要求
- 准确：人名、地名、功法名、境界名必须与原文一致；不确定就写「原文未明说」。
- 具体：写清章号；关键剧情写结果，不要含糊。
- 逐章一句话必须覆盖本段全部章节（100 章就是 100 条），这很重要。
- 只写自己负责的笔记文件，不要修改别人的文件，不要动 work/ 下的公共文件。
- 完成后：完成共享任务，并给 lead 发一条 150~300 字的「本段核心内容」消息。
