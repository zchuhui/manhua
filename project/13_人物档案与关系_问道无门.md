# 13 人物档案与关系 · 《问道无门》

## 一、主角
### 庄飞（前世：顾无门，道号"无门"）
- 年龄/身份：17岁，青芜宗杂役峰杂役；前世为散修"问道榜第一"。
- 外在目标：进仙盟、拿《飞升名录》原件、关闭飞升献祭。
- 内在缺陷：极度不信人；把"真相/变强"当唯一安全感；习惯独自背负；对"飞升"有创伤性执念。
- 真正需要：承认自己当年也是旧规则受益者（他杀过的人里有献祭者的家属），学会"为人留门"。
- 能力：识破（规则见12号）；擅长用低阶材料改造功法/丹方/阵法；战斗靠准备与布置。
- 弧光：报复/自保 → 揭真相 → 建"无门" → 守门人。
- 退场：第七卷成为守门人（保留力量，永世不飞升）。

### 裴照（核心对手/旧友）
- 身份：仙盟接引院接引使；前世与顾无门同榜、唯一好友。
- 目标：维持飞升秩序，保住妹妹裴小满（在名录上，被上界当人质）。
- 方法：操控名额、篡改名录、以"资质"分配命运；必要时杀人灭口。
- 自认为正确：不放人上去，上界会直接下来收割，死得更多；他每年亲手送人，自己也在名单上。
- 缺陷：把"牺牲少数"当理性；不敢面对旧友；对妹妹的私心让他一再破例。
- 弧光：对手 → 被揭穿 → 反水（卷六）→ 被废修为、留无门教书。
- 知情边界：卷四确认主角身份（名录共鸣）；卷五知道主角拿了名录；卷六摊牌。

### 沈青梧（女主/体制内同盟，独立目标）
- 身份：仙盟执法堂查案官；出身中州没落世家。
- 目标：查清三年前"天泉案"（其师被定为"私改名录"处死，她不信）。
- 方法：讲证据、走程序；不完全信主角，也不完全信仙盟。
- 与主角关系：卷四互相利用 → 卷五合作 → 卷六因"公开真相的时机"冲突 → 卷七和解/或分道。
- 退场：存活，接掌执法堂改革（若主角选择分阶段公开，她是执行者）。
- 独立线：她的查案推进"名录原件"线索，不依赖主角救场。

### 苏小满（宗门丹道天才，独立目标）
- 身份：青芜宗杂役出身，后入外门丹房；父母死于"名额税"。
- 目标：证明"不靠飞升也能证道"，成为下界第一位"无门丹师"。
- 与主角：从互相看不顺眼到合作；她的丹道天赋+主角的识破=改造丹方组合。
- 弧光：自卑→自立→无门学院丹院主；不退场，不依附。

## 二、宗门与仙盟
- **汤伯**：杂役峰老杂役，实为前世顾无门的旧仆/守门人；用名录残页把主角"捞"回来。隐瞒身份到卷三；卷六战死。
- **赵守拙**：青芜宗内门长老；目标保宗门、争名额；亦正亦邪；卷一末注意主角；卷三与主角合作/对抗；卷六站队主角（或战死，视卷三测试反馈）。
- **阿福**：杂役少年，被主角所救；目标活下去、变强；班底之一；存活。
- **青芜宗宗主·周鹤年**：把弟子当"名额"卖给仙盟的献祭中介；卷三被揭穿；下场（废/死）卷三定。
- **陆见渊**：仙盟录名司主；目标维持名录；卷五对手；卷六投降/被废。
- **屠玄**：天泉司主；目标保天泉；卷五对手；卷六死。
- **少司命**：上界使者，云京"收债人"；卷六/卷七出场；傲慢、强横，但按契约行事；卷七被逼退。
- **裴小满**：裴照之妹，名录上的人；卷五揭示；卷六/七成为裴照选择的筹码。

## 四、退场与牺牲原则
- 不靠滥杀制造重量：汤伯之死要有"传承"作用；赵守拙若死要完成立场弧光；裴照被废而非死，保留"活着的代价"。

## 五、主角语言与人设：嘴贱（2026-11-05 补充，正式设定）

**结论：原设定里没有正式写"嘴贱"，正文也没落地——这是缺失，现补为庄飞的核心辨识度。**

### 1. 定义
嘴贱 ≠ 骂脏话。庄飞的嘴贱是：**看破了还要说破，专挑对方最疼的地方说，用最便宜的话把对手架到高位上，再让他自己摔下来。**
三分毒舌 + 两分自嘲 + 一分怂。

### 2. 五条使用规则
1. **对强者贱**：打不过也嘴硬，嘴完就跑/挨打；越强越爱撩（"赵长老英明神武，就是眼神不太好"）。
2. **对弱者护**：不欺负比自己更弱的人；对杂役、阿福、苏小满这类人，嘴是软的。
3. **对朋友损**：越熟越损（"阿福，你再哭，北院的雪都要化了"），损完给好处。
4. **对敌人诛心**：不骂娘，专揭短、专戳利益（"孙执事，你炸的炉都记在损耗里吧？"）。
5. **对权威阴阳**：表面恭敬，句句带刺；不正面顶撞，让对方吃哑巴亏。

### 3. 语言工具箱
- 反问、抬杠、偷换概念、用对方的话堵对方；
- 把专业术语翻译成大白话（"你这丹方，缺一味引药，说白了就是炒菜没放盐"）；
- 给对手起外号（孙不理→"孙不熟"；钱贵→"钱抠抠"；马跃→"马后炮"；周明堂→"周公子"带笑）；
- 越紧张越贫，越危险越损（用嘴掩饰算计）。

### 4. 密度与代价
- 每章2—4句"贱话"；每3章一次"贱到对方破防"的名场面；每卷最多1次"贱过头吃大亏"；
- **嘴贱必须付代价**：被记恨、被罚、被打、被苏小满拆台、被赵守拙扣月钱——不能零成本；
- 后期升级：从"嘴上占便宜"到"用嘴布局"（激将、套话、诱使对手犯错）。

### 5. 与"识破"的关系
看破＋说破＝贱；但**不全说破**，留一手。识破是刀，嘴是刀鞘上的响。

### 6. 禁用
- 不拿死者、无辜者、女性容貌开黄腔；
- 不为了嘴贱而降智；
- 不重复同一句口头禅（不设"你妹"作为固定口头禅）。
