# 05 初步分析 · 仅限第1~20章

> 证据与逐章表见 research/wangu-study.md 第14节；本条目标出编辑层判断与"下一步要验证什么"。**不对全书下结论。**

## 一、本批四条因果链
1. **冲脉—开脉—备战**：材料与玉佩(0010) → 炼针配药通脉(0011) → 开脉(0012) → 亮七脉轮(0018) → 炼丹备战(0019-0020)。链条完整，但"剩余脉轮如何开齐"缺过程（D-011）。
2. **蓝飞—王峰—蓝玄**：败北失玉(0008-0009) → 王峰定计＋栽赃(0012) → 反杀与开除(0013-0015) → 蓝玄下战书(0018)。升级阶梯清楚，但关键反制过程省略（D-015）。
3. **公会—术炼线**：课堂折服(0001-0002) → 洛云裳借知识晋级(0016) → 贾荣反杀清障(0016-0017) → 牵线收徒(0017) → 借贾荣炼丹(0019-0020)。短线伏笔回收较扎实。
4. **制度展示**：学院规矩(0012) → 公会袭击无后果(0017) → 考场改规则(0018)。制度强度不一致（D-013/D-014）。

## 二、由选择自然引发 vs 依赖便利
**自然引发**：课堂露才→洛云裳求助→术炼公会→贾荣交易；击败蓝飞→蓝飞报复→栽赃→反杀→蓝飞开除→蓝玄出头；洛云裳把主角的知识用在自己的考核上（0016），是前文承诺的兑现。
**便利安排**（判断，可能削弱艰难感）：蓝飞随身玉佩恰好是主角急需的稀有材料（0009）；贾荣恰好中毒且主角能诊断（0003）；刘一天恰好施暴、封不平恰好被请到（0013-0014）；主角反栽赃的手法完全省略（0013-0015）；蓝玄当众承认弟弟罪状，替主角削弱王峰（0018）。

## 三、重复模式（初现）
- "被低估→亮实力→围观震惊"在20章内至少5次：俞和正(0006-0007)、蓝飞(0008-0009)、王峰规则(0018)、蓝玄口头(0018)、罗兰朵(0020)。
- 胜利手段高度集中于"前世知识/经验优势"；主角几乎无失手。
- 资源多次来自对手（蓝飞玉佩、贾荣材料与炼丹能力）。
- 女性角色功能待观察：罗兰朵（高傲女神）、秦茹雪（维护者）、梦舞（受害＋被轻薄）。

## 四、人物逻辑候选问题（需后续验证）
- 王峰：作为教师公然改规则、合谋校外杀人；且已从蓝飞处得知主角力破千斤，仍假设主角"展示不出脉轮"（D-014）。
- 许寒/公会：贾荣当众以神识重创同僚，仅令其告老，未追责（D-013）。
- 蓝玄：公开承认弟弟罪状以博声望，再为家族颜面挑战主角；动机可解释但时机与方式更像为主角送对手。
- 贾荣：从怨恨到依附有利益动因（炼魂术、性命、地位），本批可信度尚可；但"跪地认主"速度偏快。
- 梦舞：被主角侵犯却"说不出声"，无规则解释（D-012），须在后续确认是否为一次性桥段。

## 五、体系与数值
- 境界：脉轮开≠一元境（需凝元气），0018亮七脉轮仍未成武士，二元表述基本自洽。
- 矛盾点：0012"打开三道" vs 同章五道 vs 0018"七道"（D-011）；洛云裳0001"二星四象" vs 0020"三星四象"（D-017待核）。
- 术炼：新增"成品提纯/纯品丹"规则；主角以高级学徒魂力完成士级操作，依赖前世经验，暂可接受但需设定代价上限。
- 战力边界：主角尚未与老练武士/武师交手；0021决斗是第一次真正测试。

## 六、值得保留的优点（避免"合理化"抹掉爽感）
1. 开篇20章的"能力反差具象化"（专业答题、症状推断）比旁白更强。
2. 升级阶梯清楚：路人→同辈→教师→兄长，冲突逐级放大。
3. 短线伏笔回收干净：0016洛云裳用0001-0002的知识通过考核。
4. 反派有可理解的欲望（贾荣保右手与身份；王峰保外甥；蓝玄保家族颜面）。
5. 有日常与幽默（韩柏借钱、陆宇炼丹失败），节奏有缓冲。
6. 情感钩子：古飞扬塑像、杨迪师生关系（0017）。

## 七、结论边界与下一步验证
本批只能说明"开篇单元的结构特征"，不能外推全书。下一步（0021—0030/0035）重点验证：决斗结果与代价、蓝家/李家反应、术炼师徒线、时间与成长速度锚点、女性角色处理是否延续。
