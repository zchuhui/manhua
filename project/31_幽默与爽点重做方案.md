# 31 幽默与爽点重做方案（诊断＋改法＋样章）

> 触发：用户反馈"读了感觉缺乏幽默与爽点"。本文件记录诊断证据、改法与重写计划。
> 样章：drafts/问道无门/样章/第003章_重制_幽默爽点版.md（对照正文第3章）。

## 一、我同意，而且问题可定位（有文本证据）

### 1. 爽点"三拍"缺两拍
一个有效爽点通常是：**憋屈（立flag/被轻视）→ 反转（低成本破局）→ 余韵（围观换算＋当场收益）**。
当前写法：
- **憋屈不足**：对手的"装逼"通常只有一两句（第3章孙不理只说"炼不成打断腿"），没有把赌注、围观、退路都押满；
- **反转过快**：主角几乎不承压，识破一开就赢，读者没有"憋着"的过程；
- **余韵被砍**：赢完立刻"鼻血/被叫走/被通缉"，代价和爽点挤在同一场里，赢的痛快被自我削弱。
  例：第3章赢完孙不理，紧接着就是"鼻血、两天三次、飞升台钟声"；第9章赢完加试，立刻"你到底是什么人"。爽点没有落袋时间。
- **收益不具体**：赢了之后主角拿到什么？第3章只拿到"赵长老一句明天来内门"；没有当场可量化的收益（钱、徽章、名额、追随者、对手的丑态）。

### 2. 幽默单薄
- 笑点集中在主角"嘴毒"（"你妹""傻帽"），且集中在前几章；第二卷后几乎没有笑点；
- 配角没有喜剧人格：阿福只会哭、苏小满永远冷脸、石大牛憨但没有戏、孔七机灵但没场景；
- 缺"情境喜剧"：误会、自我攻略、装逼翻车、围观群众过度解读这些网文最稳的笑料来源基本没用；
- 叙述腔调偏冷、偏文学，缺少主角内心吐槽与夸张修辞。

### 3. 节奏与文本问题
- 章节太短（大量500—1,800字），一个冲突没有空间完成"起承转合"，笑点/爽点刚起就断；
- 合并稿里有重复段落/重复句（例：第9章"阿福站在人群最前面"出现两次；"孙执事。马跃忽然开口"出现两次），打断阅读。
- 主角人设写成"冷静工程师"，但他设定是"腹黑、嘴毒、扮猪吃虎"——人设没落地。

### 4. 但不要推倒重来
规则清楚、伏笔有账、代价感真实，是这本的底子；问题不是设定，是**爽点与幽默没有做工程设计**。

## 二、改法：把"爽点"当工程做

### 1. 六拍爽点公式（每场冲突用）
1. **立flag**：对手/权威把话说满，押上具体赌注（徽章、名额、灵石、当众磕头），围观者起哄；
2. **压低姿态**：主角不接招、示弱、讲条件，让对手更狂；
3. **轻成本破局**：用最便宜/最不体面的东西（药渣、常识、规则漏洞）翻盘；
4. **围观换算**：让旁观者用"钱/地位/境界/名额"把主角的战果换算出来（"这一炉值六十块灵石""他一个杂役把丹师徽章拿了"）；
5. **打脸落地**：对手的具体丑态（手抖、说不出话、被自己立的誓架住），不要只写"脸色铁青"；
6. **当场收益**：徽章/灵石/名额/追随者/对手的保证，落袋为安；**代价延后到下一章**再付。

### 2. 频率与类型
- 每章至少1个小爽点或笑点；每3章1个中爽点；每10章1个大爽点（卷末级）；
- 类型轮换：知识降维 / 规则反杀 / 扮猪吃虎 / 误会捧杀 / 群像打脸 / 收益落袋；
- 每章结尾留"钩子"，但钩子前必须先给一口"糖"。

### 3. 幽默的四个来源
1. **主角内心吐槽**：每章2—4处，短句、毒舌、自嘲（"这方子谁写的，该拉去喂猪"）；
2. **捧哏配角**：
   - 阿福：憨直捧哏，负责把主角的骚操作喊出来；
   - 孔七：机灵狗腿，负责算钱、传谣、补刀；
   - 石大牛：一本正经地离谱（体修逻辑）；
   - 苏小满：冷面吐槽，专门拆主角的台；
3. **对手自我攻略**：对手/围观者脑补主角"深不可测"，越解释越离谱；
4. **情境反差**：主角想低调却被架上去；想装怂结果被当成高人；把"识破"误认成算命/神棍。

### 4. 人设落地
- 庄飞：表面懒散嘴贱，实际算得很精；能占便宜绝不客气，但底线是"不拿无辜者垫背"；
- 每次"嘴贱"要付小代价（被记恨/被罚/被苏小满拆台），不能零成本。

## 三、第3章重制版做了什么（对照样章）
- 加赌注：孙不理押上"丹师徽章＋见你绕道走"，主角反问"你这徽章不够买我一条腿"；
- 加围观群像：丹童端反茶碗、钱贵被药汁溅脸、外门弟子现场算账；
- 加阿福捧哏（跑腿掉鞋）；
- 把收益落袋：主角当众摘走孙不理的徽章；
- 群像换算："一筐药渣＝六十块灵石"；
- 代价后置：赢完、拿了徽章，才流鼻血、听见钟声；
- 保留赵守拙钩子与"可惜了"的余味。

## 四、执行计划
1. 先按新调性重写第1—10章（每章2,400—3,000字），同步修正重复段落；
2. 第11章起按"六拍公式＋每章一笑点"写；第36—50章扩写时一并补爽点；
3. 每批更新读者数据（docs/data）与编辑记录；
4. 每卷末做一次"爽点密度检查"：数一数本章有几个"立flag→翻盘→换算→收益"。


## 五、补充：主角"嘴贱"设定（2026-11-05）
- 原设定文档未正式写入"嘴贱"，正文只有零星"你妹/滚"等，密度过低；现已把「嘴贱」补为庄飞核心辨识度（详见13号文档第五节）。
- 写作检查：每章数一数"贱话"是否≥2句、是否至少1次"看破+说破"、是否给嘴贱安排了代价。
