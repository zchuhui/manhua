# 11 故事总纲 · 《问道无门》

> 状态：第三、四阶段成果（结局锁定＋倒推大纲＋规模控制），**待你确认**；确认后我才写第一卷详细大纲与正文。
> 依据：你的三项选择——方案二《问道无门》、爽点=知识降维、结局=保留力量的"守护者结局"。
> 名称（庄飞、顾无门、裴照、沈青梧、青芜宗、识破）均可改，先按此推进。

## 一、一句话核心
前世"问道榜第一"的散修顾无门，在飞升时撞破"飞升即献祭"的真相被害；他带着《飞升名录》的残页重生为仙盟最底层宗门"青芜宗"的杂役庄飞，从杂役一路爬到仙盟中枢，只为拿到名录原件、关掉那座吃人的飞升台。

## 二、主角与对手
- **庄飞（前世：顾无门，道号"无门"）**：外在目标——进仙盟、拿名录、废飞升制度；内在缺陷——极度不信人，把"真相与变强"当作唯一安全感，习惯独自背负；真正需要——承认自己当年也是旧规则的受益者，学会"为人留门"。
- **裴照（接引使，前世唯一好友）**：目标——维持飞升秩序，用下界修士的命供养上界；方法——操控名额、篡改名录、以"资质"分配命运；自认为正确——不放人上去，上界就会下来收割，死得更多。他每年亲手送人上飞升台，自己也在名单上；妹妹裴小满（或母亲）是上界捏在手里的"人质"。

## 三、结局锁定（先定终局）

### 3.1 最终冲突
主角与"飞升献祭制度"的冲突，不是单人决斗，而是"关闭通道"的复合战争：上界第二次降下接引军，主角在下界联军与"无门"学院支持下，于第九飞升台改写《飞升名录》、关闭天泉；上界使者降临，主角以"识破＋名录＋提前布置"逼退/重伤使者；裴照反水；仙盟残余投降；下界进入"无门"时代。

### 3.2 为什么必须主角亲自解决
1. 名录残页在他魂魄里，只有他能改写名录（上界承认"残页之主"）；旁人持名录会被反噬、被上界定位。
2. 他是唯一"看过天泉真相还活着"的人；他的识破能看破上界使者功法的破绽，是下界唯一能伤上界的手段（第五卷后能力升级）。
3. 他的身份（被献祭的问道榜第一）让他成为下界修士的旗帜，换人无法联合九域。
4. 上界会追杀残页持有者，他躲不掉。

### 3.3 为什么不能靠更强的外援或临时能力
- 仙盟高层是既得利益者；下界最强者（大乘/渡劫）要么不知真相，要么不敢飞升、不敢反抗；上界力量高于下界上限。
- 识破对"天泉/云京之物"无效，直到他融合名录残页（第五卷）才能部分看破上界功法；没有"临时觉醒"。
- 关闭通道需要"名录＋九座飞升台控制权＋下界气运"三件套，缺一不可，只能逐一布局。

### 3.4 主角必须做出的艰难选择
- **终局二选一**：关闭通道（下界灵气短期枯竭、上界报复、可能死很多人）vs 继续献祭（每甲子死人，但秩序稳定）。他选择关闭，并承担"第一批死的人"的骂名。
- **对裴照**：杀、放、还是废？他选择废其修为、留其性命、让他教下一代（比死更重的赎罪），并接受裴照恨他。
- **公开真相的节奏**：一次性公开会引发下界宗门争夺残存资源、大乱；他选择"先联合九域、再分阶段公开"，因此放弃"一夜昭雪"的快意。

### 3.5 他付出的不可逆代价
1. 永世不能飞升（识破之眼与名录残页绑定，飞升即被上界定位炼化）。
2. 每十年重写一次名录，承受反噬：寿元与记忆一点点缺损——**力量保留，记忆不保留**（为余韵与续作留口）。
3. 与裴照的友谊永久破裂：他亲手废掉旧友。
4. 失去"问道榜第一/无门散人"的名分，成为不能公开称尊的守门人。

### 3.6 开篇核心问题如何在结尾得到回答
- 开篇问题："飞升的人到底去了哪里？为什么问道榜第一会死？"
- 终局回答："去了云京，被炼成天泉；我关掉了通道，从此没有人再被炼。"
- 主角从"想飞升的人"变成"守住门的人"——这就是"守护者结局"。

## 四、倒推大纲（从终局往前）

> 每个转折均含：前置原因 → 人物行动 → 直接结果 → 长期后果。

### T6 终局必要条件（第七卷）
- 前置原因：第六卷通道暂关、上界使团退去，但"归墟"更上层注意到下界。
- 人物行动：主角重建"无门"，联合九域残存势力，暗中重写名录；裴照被废后留在无门教书。
- 直接结果：第二次上界降临，主角在第九飞升台完成改写，斩断收割链。
- 长期后果：下界灵气缓慢恢复、上界暂时退去；主角成为守门人，每十年承受一次反噬。

### T5 第六卷转折：上界降临
- 前置原因：第五卷主角拿到名录、被发现"名录认主"。
- 人物行动：上界使团降下，要求仙盟交出"名录之主"；主角联合九域宗门、旧部、被压迫的散修，打九座飞升台之战。
- 直接结果：通道暂关、使团退去；汤伯战死；裴照在关键时刻反水帮主角（或被迫选择）。
- 长期后果：下界进入"无门"时代的雏形；主角被上界标记，成为下一个"必须清除"的目标。

### T4 第五卷转折：进入仙盟、拿到名录
- 前置原因：第四卷问道榜揭晓"飞升=献祭"，主角被仙盟通缉。
- 人物行动：以"问道榜第一"的身份反入仙盟录名司；与执法堂查案官沈青梧互相利用；发现上界也在被更上层收割。
- 直接结果：拿到名录原件；名录认主；裴照的困境曝光（妹妹/母亲是名单上的人）。
- 长期后果：主角从"复仇者"变成"制度破坏者"；沈青梧从体制内查案者转为同盟（或分裂）。

### T3 第四卷转折：问道榜
- 前置原因：第三卷揭出宗门把弟子"卖"给仙盟的献祭中介。
- 人物行动：主角以外门/内门身份参加问道榜，一路以"识破"破题、破局。
- 直接结果：决赛夜，第一名被"迎上飞升台"，主角看破天泉献祭，当众揭穿（第一次大揭秘）；裴照确认他身份。
- 长期后果：主角成为下界修士的旗帜；仙盟开始全力追杀；旧友线正式对撞。

### T2 第三卷转折：内门与"献祭中介"
- 前置原因：第二卷主角在外门大比中冒头，被内门与仙盟巡查注意。
- 人物行动：进入内门，与长老赵守拙合作/对抗，查宗门"供奉名单"。
- 直接结果：揭穿宗主与仙盟的"献祭中介"（把资质不够的弟子冒充"飞升候选"送走）；宗门分裂。
- 长期后果：主角第一次知道"名额可以买卖"，也第一次意识到仙盟不是铁板一块。

### T1 第二卷转折：外门与名额税
- 前置原因：第一卷主角在杂役峰露头，被迫进入外门。
- 人物行动：外门大比中用"改造丹方/功法"带杂役班底逆袭；发现宗门按名额缴税、压缩底层资源。
- 直接结果：站稳外门、组建班底；得罪内门天骄与执事。
- 长期后果：班底成为后续九域联军的种子；"名额税"把个人恩怨升级为制度冲突。

### T0 第一卷/开篇触发事件：杂役峰与名录残页
- 前置原因：主角重生在青芜宗杂役峰，记忆完整、修为归零，带着名录残页。
- 人物行动：用识破看穿杂役管事用废丹克扣、用残方骗人；救下吐血少年阿福；在丹房当众破局，被长老赵守拙注意。
- 直接结果：从杂役进入"可被看见"的位置；识破之力第一次使用，引发名录波动，被接引使裴照察觉"青芜宗方向有异常"。
- 长期后果：裴照下宗巡查；主角获得第一块线索（飞升台废墟遗骨）；主线的"旧日恩怨"与"世界秘密"同时启动。

## 六、核心主线与支线（只留服务主线的）
- **核心主线**：关闭飞升献祭制度（每卷都推进：真相层级+1、力量层级+1、盟友层级+1）。
- **支线1 宗门/仙盟名额政治**（服务主线：展示制度如何吃人）。
- **支线2 裴照旧谊**（服务主线：对手也是祭品，终局选择有情感重量）。
- **支线3 沈青梧查案**（服务主线：体制内视角，提供情报与道德冲突）。
- **支线4 苏小满"无门丹道"**（服务主线：证明"不靠飞升也能证道"，是结局的民间基础）。
- **支线5 杂役班底成长**（服务主线：终局联军的种子）。
- **禁止**：新增更高位面；让主角飞升上界升级；用"幕后黑手"临时加码。

## 七、力量体系上限与地图边界
- 境界（下界，9阶）：炼气（1—9层）→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫。渡劫后可"飞升"（真相=献祭）。
- 上界"云京"：真仙/玄仙/金仙只作为背景压力，**本书不让主角升上去**；上界出场以"使团/接引军"为限。
- 战力边界：主角跨一阶靠布置与识破，跨两阶只能逃或借势；同阶可胜但不无敌（详细规则见12号文档）。
- 地图：玄洲九域（东荒—青芜宗所在、中州—天枢城、其余七域）；九座飞升台；上界云京（背景）。不新增位面。
