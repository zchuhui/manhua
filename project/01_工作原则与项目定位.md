# 01 工作原则与项目定位

## 项目目标
以《万古至尊》为研究对象，创作一部全新的东方玄幻长篇：
- 保留类型吸引力：强者重生、身份反差、成长逆袭、旧日恩怨、世界秘密；
- 重新设计人物、世界观、核心矛盾、事件链与结局；
- 使新作情节更紧密、人物更可信、规则更稳定、能够完整收束；
- 不是润色，不是换名复述，不沿用原作辨识度高的场景组合、关系网、宝物体系与事件顺序。

## 工作原则（用户指定）
1. 先研究，后设计，再写正文；完整大纲经用户确认前，不进入长期正文创作。
2. 不声称读过实际没有读取的内容。
3. 原作事实、推断、新作设想必须明确区分。
4. 不预设原作烂尾/逻辑崩坏；所有诊断必须有具体情节证据。
5. 长文件分批读取，维护阅读进度与结构笔记；不凭简介、开篇或零散抽样推断全书。
6. 笔记、大纲、设定、伏笔、修改决策保存为可持续更新的项目文档，不依赖对话记忆。

## 阶段流程
1. **第一阶段 原作结构诊断**（当前）：全量覆盖阅读 + 分篇章诊断 + 全书诊断报告。
2. **第二阶段 新作方案**：三个独立方案（含 10 项要素），推荐一个并等待用户选择。
3. **第三阶段 先定结局再倒推大纲**：终局条件 → 中后期转折 → 中期认知 → 前期选择 → 开篇触发。
4. **第四阶段 规模控制与分卷设计**：6~8 卷、60~90 万字规划、力量体系上限、人物出场/退场计划。
5. **第五阶段 正文**：用户确认完整大纲后，先第一卷详细大纲 + 前三章试稿，之后每批 2~3 章 + 编辑记录。

## 标注与证据强度
- 【事实】直读原文（A 级证据，附章号）。
- 【检索】原文关键词/片段检索（B 级，附章号）。
- 【推断】分析判断（写明依据与置信度）。
- 【参考】引用既有团队笔记（C 级，需回原文核对后才可升级）。
- 【待核】留待后续批次验证的假设或事实。

## 目录规范
- project/ 本项目文档；project/notes/ 分批阅读笔记。
- 不修改 work/ 与 notes/ 下上一轮通读产物；只读引用，引用时标明来源。
- 已写定内容不悄悄修改：变更走 09_设定变更记录.md。

## 本轮（第01批）范围
只执行：文件识别、规模统计、阅读计划、首批（第1~20章）阅读、结构笔记、初步分析。
不进入全书结论、不做新作方案、不写正文。
